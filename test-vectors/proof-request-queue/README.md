# Proof request queue — cross-language test vectors

Generated by Rust, asserted by the Rust, o1js and Solidity implementations. The
encodings pinned here are consensus-critical: a divergence between the SP1
guest and the Mina circuit produces proofs that verify on one side and not the
other, and a divergence in the storage layout makes the guest read the wrong
words.

## Files

| File | Generator | Pins |
|---|---|---|
| `request-leaf-vectors.json` | `cargo run -p nori-hash --bin request_leaf_vectors` | Poseidon leaf packing for one queue request |
| `proof-outputs-vectors.json` | `cargo run --example proof_outputs_vectors -p nori-sp1-helios-primitives` | The 220-byte `ProofOutputs` encoding |
| `entry-location-vectors.json` | `cargo run --example entry_location_vectors -p nori-sp1-helios-primitives` | Storage slots of `head` and each queue entry's five words |

Regenerate with:

```sh
cargo run -q -p nori-hash --bin request_leaf_vectors \
  > test-vectors/proof-request-queue/request-leaf-vectors.json
cargo run -q --example proof_outputs_vectors -p nori-sp1-helios-primitives \
  > test-vectors/proof-request-queue/proof-outputs-vectors.json
cargo run -q --example entry_location_vectors -p nori-sp1-helios-primitives \
  > test-vectors/proof-request-queue/entry-location-vectors.json
```

## Consumers

The files are vendored (copied, not symlinked) into the SDK, following the same
convention as the integrity constants. A copy must be refreshed whenever the
source is regenerated.

| Vendored copy | Asserted by |
|---|---|
| `nori-bridge-sdk/o1js-zk-utils/src/test-vectors/proof-request-queue/` | `proofRequestQueueVectors.spec.ts` (leaf packing, `ProofOutputs` bytes) |
| `nori-bridge-sdk/contracts/ethereum/test/test-vectors/proof-request-queue/` | `NoriProofRequestQueue.ts` storage-layout suite (entry locations) |

## Changing a vector

A changed `leaf` or `bytes` value means the wire format moved. That is a
breaking change for any deployed pair of circuits, so it needs the Rust guest,
the o1js circuit and the deployed verification key to move together.
